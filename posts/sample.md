# 샘플 포스트

블로그 글을 여기에 작성하면 자동으로 표시됩니다.

## 마크다운 지원

- 제목, 본문, 리스트 등 모든 마크다운 형식 지원
- 코드 블록도 가능합니다

## 인터랙티브 코드 실행

Run 버튼을 클릭하면 미리 정의된 결과가 표시됩니다.

```python
print("Hello, World!")
---output---
Hello, World!
```

```javascript
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(n => n * 2);
console.log(doubled);
---output---
[2, 4, 6, 8, 10]
```

## 일반 코드 블록

구분자가 없는 코드 블록은 기존과 동일하게 표시됩니다.

```python
# 이 블록은 실행 버튼이 없습니다
def greet(name):
    return f"Hello, {name}!"
```
